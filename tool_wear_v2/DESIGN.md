# 공구 마모 측정 v2 — 설계 문서 (자세정렬 기반)

## 0. 한 줄 철학
> VB(새 공구 대비 날 후퇴량) = **정렬이 정확하면 측정은 그냥 기하학(빼기)**.
> 그래서 ML을 **"마모 인식"(형상마다 재학습·라벨링 필요, 일반화 안 됨)** 이 아니라
> **"자세 정렬"(자기지도, 라벨 0, 형상 무관)** 에 전부 투입한다.

기존 v3의 한계: `best_model_Al.h5`(특정 알루미늄 공구로 학습된 분할 CNN)에 의존 →
형상/재질/조명이 바뀌면 Edge/Wear 분할이 무너짐. 손라벨링 비용도 큼.

---

## 1. 입력 / 촬영 조건 (확정된 사실)
- 공구는 **장착된 채 연속 회전**하며 촬영. 회전속도·촬영속도 일정 → **프레임 간 각도 간격 Δθ 일정**(예: 1°).
- **장착은 항상 동일** → 새 공구 시퀀스와 마모 시퀀스의 위상(phase)이 (거의) 고정.
  남는 어긋남은 **1° 미만(sub-degree)** 수준.
- 카메라 **2대 동시(시간 동기)**:
  - **밑면 카메라**: 아래에서 위로, 끝면(end face) 촬영. 두 날이 항상 한 프레임에 보임.
  - **옆날 카메라**: 옆에서, 여유면(flank) 촬영.
- **날 2개**(2-flute) → 외형이 **180° 주기**로 반복(2겹 회전대칭).
- 기준선 = **공구 자체 형상**(물리 마커 없음).
- 측정량: **둘 다 VB = 새 공구 대비 날이 얼마나 후퇴(깎여나감)** [μm].

### 시간 동기의 활용
프레임 i는 두 카메라에서 **같은 회전각**. 회전이 더 잘 보이는 쪽(옆날)에서 각도를 추정해
밑면에 적용·교차검증 가능.

## 2. 전체 아키텍처

```
                 ┌─────────────────────────────┐
 새 공구 시퀀스 →│  자세 추정 (ML 코어, 자기지도) │→ 프레임별 연속 각도 θ(i)
 마모 시퀀스   →│  Siamese 회전 회귀기          │
                 └─────────────────────────────┘
                              │
            ┌─────────────────┴───────────────────┐
            ▼ (옆날: 시퀀스 위상정렬)              ▼ (밑면: 평면 회전정합)
  같은 각도로 이웃프레임 보간            log-polar+위상상관으로 회전각 추정
            │                                      │
            ▼                                      ▼
   새/마모 윤곽 추출(실루엣)              새/마모 끝면 회전정렬
            │                                      │
            └──────────────┬───────────────────────┘
                           ▼
              VB = (새 윤곽 − 마모 윤곽) 후퇴거리 → μm
```

## 3. ML 코어 — Siamese 회전 회귀기 (자기지도)

### 목적
프레임의 **연속 회전 자세**를 sub-degree로 추정. 마모가 껴도 **회전만 보고 마모는 무시**.

### 데이터 / 라벨 (손라벨링 0)
- 한 시퀀스에서 임의의 두 프레임 (i, j).
- **정답 = (j − i) · Δθ** (도). 실제 회전 데이터라 "1° 회전이 실제로 어떻게 보이는지"를 진짜로 학습.

### 주기성 처리 (날 N개 → 360/N° 주기)
각도를 직접 회귀하면 wrap-around·대칭 모호성이 생김.
→ 타깃을 **(cos(N·θ), sin(N·θ))** 로 인코딩. N=2(2-flute) → 180° 주기를 자연히 반영.

### 모델
- 공유 인코더 E(작은 CNN) → 각 프레임 임베딩.
- 두 임베딩을 결합 → MLP → **(cos, sin)** 2출력 (L2 정규화).
- 손실: `1 − cos(Δ̂ − Δ)` 형태의 각도손실 또는 (cos,sin) MSE.

### 마모 불변성 강화
- 새+마모 시퀀스를 **같이** 학습.
- (선택) 합성 마모 증강: 새 공구 날을 디지털로 갈아낸 변형을 "같은 각도"로 강제.

### 검증 (가장 먼저 할 것)
- 새 공구 시퀀스로 학습 → 마모 시퀀스에서 각도 예측.
- **자가검증**: 두 날이 180° 떨어졌는지, 한 바퀴 적분이 360°가 되는지.
- 합격 기준: sub-degree(예: < 0.3°) 일관성.

## 4. 파이프라인 A — 옆날 (시퀀스 위상 정렬)

1. **팁 윗부분 크롭** (두 날 동시 노출 방해 제거), 한 바퀴+ 촬영.
2. 회전 회귀기로 **프레임별 연속 각도** → 각도축 구성.
3. 새 공구에서 **기준 자세(날 수직) 정의** → 새·마모를 **같은 각도로 이웃 두 프레임 보간**
   (프레임 간격보다 미세하게 맞춤 = sub-degree 해소).
4. **날 윤곽 추출**(공구 vs 배경 실루엣 — 마모 라벨 무관).
5. **VB = 같은 각도에서 새 윤곽 대비 마모 윤곽의 후퇴거리** → μm.
6. **두 날 각각**(180° 매칭).

## 5. 파이프라인 B — 밑면 (평면 회전 정합)

끝면 전체가 보이므로 "프레임 고르기"가 아니라 **이미지 평면 회전(자유도 1)** 문제.

1. 가장 선명한 프레임(또는 여러 장 정합 평균).
2. 공구 중심(=회전축) 추정(실루엣 무게중심).
3. **log-polar(warpPolar) + 위상상관** → 새↔마모 **평면 회전각** 추정(서브픽셀=sub-degree).
4. 축 중심으로 마모를 회전 정렬.
5. **VB = 코너/날 윤곽의 baseline 대비 후퇴** → μm.
6. 180° 대칭 모호성 → 두 날 마모가 다르면 자동 해소.

> 밑면은 학습 없이 **고전적 방법만으로 PoC 가능**(poc_endface_rotation.py) — 가장 빠른 검증 경로.

## 6. 측정(VB) — 정렬 후엔 기하학

정렬이 끝나면 VB는 **윤곽 위치 빼기**:
- 같은 각도(옆날) 또는 같은 회전정렬(밑면)에서
- 새 공구 날 경계선 위치 − 마모 날 경계선 위치 = **후퇴거리(px)**.
- 무거운 변화검출 net 불필요. 윤곽 추출만 robust하면 됨(실루엣 = 마모라벨 무관).
- (선택) 합성 후퇴로 학습한 가벼운 보정 net만 얹어 노이즈 강건화.

### μm 환산 (v3의 825.6 상수 개선)
- 상수 하드코딩 대신 **알려진 치수(예: 공구 직경/생크 폭)나 스케일바**를 입력받아
  px→μm 자동 산출. 배율이 바뀌어도 유효.

## 8. 개발 순서 (위험도 순)
1. **밑면 log-polar 회전 PoC** — 학습 0, 데이터 한 쌍이면 즉시 검증. → `poc_endface_rotation.py`
2. **자세 회귀기 프로토타입** — 자기지도 학습 루프(+합성 데이터로 즉시 실행). → `pose_regressor.py`
3. 옆날 보간·윤곽 추출 → VB 산출 연결.
4. μm 보정 일반화, 두 카메라 동기 융합.
