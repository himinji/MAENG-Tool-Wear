# 공구 밑면(끝면) 마모 측정 — 정리 문서

> 작성: 2026-07 (SM45C 2날 엔드밀, Test1=새 공구 / Test14=마모 공구, 같은 공구의 마모 전/후)
> 목적: 특정 재료 전용이던 마모 검출 파이프라인을 **범용**으로 만들기. 그 과정에서 밑면(끝면) 측정 방법을 확립.

---

## 0. 한 줄 요약

> **정렬이 정확하면 마모 측정은 그냥 기하(빼기)다.** 그래서 "마모를 인식하는 ML"(형상·재질마다 재학습·라벨링 필요, 일반화 안 됨)을 버리고, **축을 찾아 새/마모를 정렬한 뒤 날 끝의 후퇴량을 픽셀로 세는** 고전 기하 방식으로 전환했다. 라벨링이 0이라 형상이 달라도 재사용된다.

---

## 1. 배경과 문제 정의

- 기존 v3 파이프라인: `best_model_Al.h5`(알루미늄 전용 분할 CNN)로 Edge/Wear를 분할 → 형상·재질·조명이 바뀌면 무너지고 손라벨링 비용이 큼.
- 목표: **범용화.** 1순위 축 = 재료/공구 다양화. 가장 자주 깨지는 단계 = 세그멘테이션.
- 촬영: 공구가 장착된 채 **1°마다 회전하며 촬영**(한 바퀴+ = 420장, 3088×2076 PNG). 밑면(끝면) 카메라는 두 날이 한 프레임에 보임. 2날 → 180° 주기 대칭.
- 측정량: **VB = 새 공구 대비 날이 얼마나 후퇴(깎여나감)했는가** [µm]. 마모는 **날 끝(cutting corner)에서만** 일어난다.

---

## 2. 시행착오 — 안 되던 것과 그 이유 (중요)

범용화 아이디어를 실제 SM45C 이미지로 검증하며 다음을 하나씩 배제했다.

| 시도 | 결과 | 이유 |
|---|---|---|
| Otsu 실루엣(공구 vs 배경) | ❌ 실패 | 공구가 **최고 밝기(날 면=보케 링)와 최저 밝기(몸통/홈=어두운 배경)를 동시에** 가져 어떤 임계값으로도 분리 불가 |
| 밝기 기반 겹쳐 빼기 | ❌ 실패 | 정렬을 잘해도 **조명·정반사 차이가 마모보다 커서** 마모가 묻힘 |
| 직선(Hough) 방향 정렬 | ❌ 실패 | 끝면엔 강한 직선이 여러 개(날2×양쪽) → 서로 다른 에지를 집어 회전 오답(72° vs 실제 110°) |
| 에지방향 히스토그램 정렬 | ❌ 실패 | 뚜렷한 에지 방향이 너무 적어 회전이 degenerate |
| ECC 미세정렬(밝기) | ❌ 발산 | 정반사·저대비 이미지에서 기성 서브픽셀 정합 불가 |

**핵심 깨달음:** 어려운 건 '빼기'가 아니라 **'정렬'**이다. 그리고 정렬이 계속 막힌 진짜 원인은 아래에서 밝혀졌다.

---

## 3. ★ 돌파구 — 회전축이 원인이었다

- 지금까지 모든 회전을 **크롭 중심** 기준으로 돌렸는데, **진짜 공구 축은 크롭 중심에서 ~100px 벗어나** 있었다. 100px 틀린 축으로 회전하니 아무리 각을 맞춰도 어긋났던 것.
- **해결(1단계):** 한 시퀀스 프레임 90장을 **평균** → 회전하는 날은 뭉개지고 **바깥 원(OD)만 또렷** → 원 피팅.
  - Test1 축 (899.7, 785.3), OD 반지름 650.9px
  - Test14 축 (896.5, 784.0), OD 반지름 654.5px
  - **두 축이 3px 이내로 일치** → 견고·재현.
- **효과(2단계):** 진짜 축으로 회전 정렬 → **ZNCC 0.75 → 0.976**, 차이 평균 33.7 → 12.5. 잔차는 절삭 에지에만.
- 앞서 "밝기 차가 마모를 덮어 불가능"이라던 결론은 **틀렸다** — 축 100px 오차 탓이었고, 축을 잡으니 두 사진이 거의 완벽히 겹친다. "겹쳐서 차이" 아이디어는 유효했다.

---

## 4. 완성된 밑면 파이프라인

1. **축·스케일** — 시퀀스 평균 → OD 원 피팅 → 회전축 + µm 스케일.
2. **전역 정렬** — 새/마모를 진짜 축 중심으로 회전 정렬(ZNCC 브루트포스, 0.5°→0.1° 미세). 2날 180° 모호성은 정렬 잔차로 해소.
3. **날마다 몸통 국소 정렬** — 각 날(11시·5시)을 따로, **안쪽 몸통 영역**으로 국소 정렬(dθ, dx, dy). 전역 정렬에서 남던 ~1px 프린지 제거. ZNCC 0.976→**0.989**, 0.974→**0.987**.
   - 근거: 날의 **곧은 변**(예 5:10·5:40 방향)은 형상이라 완벽히 겹쳐야 정상 = 정렬 검증 척도. 날 밑 몸통이 안 맞아 뜨는 색은 마모가 아니므로 무시.
4. **날 수직화** — 날 몸통을 정확히 **수직(90°)**으로 회전. HoughLines(0.1°)로 잔차 측정 → 보정(−2.16° → +0.02°). 이제 후퇴량이 **가로 픽셀 수**로 세진다.
5. **측정** — 절삭 에지 후퇴(가로 px) 또는 날 끝 후퇴(세로 px) × µm/px = VB[µm].

---

## 5. 픽셀 → µm 환산

- **방식:** 공구 외경(OD)을 자로 사용.
  - OD 피팅 반지름 650.9px → 지름 1301.7px
  - 물리 직경 8mm = 8000µm
  - **8000 ÷ 1301.7 = 6.15 µm/px**
- **예:** 에지가 가로로 5px 밀림 ≈ 31µm.
- **오차 요인(알고 쓸 것):**
  - OD 피팅 편차 ~0.5% (Test1 650.9 vs Test14 654.5px)
  - "피팅한 원 = 정확히 8mm 절삭원" 가정(공차·경계 위치 차이)
  - 원근 왜곡 무시(전역 균일 스케일 가정)
- **정밀 필요 시:** 알려진 치수의 **스케일바** 한 장으로 px/µm 직접 교정. 또는 OD를 절삭 코너 실제 반경으로 정의.

---

## 6. 현재 결과 (Test14)

- 국소 정렬 후 **날 끝(11시·5시) 후퇴 ≈ 0** — 자동 측정 중앙값 0µm, 눈으로도 프린지 1~2px(≈6~12µm)뿐.
- 해석: **이 시료의 두 날 끝은 마모가 거의 없거나, 있어도 이 조명의 측정 바닥(~6µm) 이하.** 방법의 실패가 아니라, 방법이 완성돼서 나온 정직한 답(공구가 아직 많이 안 닳음).
- 막힌 건 알고리즘이 아니라(축 잡으니 0.98 정렬) **이 링라이트/정반사 이미지의 측정 바닥.**

---

## 7. 범용화 — 다른 형상 공구

핵심 로직(축 → 정렬 → 기하 빼기)은 **형상 무관**. 형상마다 재학습·라벨링이 필요 없다(= 예전 Al 전용 CNN 대비 최대 강점).

| 단계 | 형상 무관? |
|---|---|
| 시퀀스 평균 → OD 피팅(축·스케일) | ✅ 회전축 있고 외경이 원이면 어떤 공구든 |
| 회전 정렬(ZNCC) | ✅ 어떤 형상이든 |
| 날 개수 대칭 | ⚙️ 파라미터 N (2날=180°, 3날=120°, 4날=90°) |
| 날 끝 위치 | ⚙️ N개 코너 자동 검출로 일반화 |
| 수직화 + 픽셀 측정 | ✅ 일반 |
| µm 환산(OD=직경) | ✅ 직경만 알면 됨 |

- 한계: 비원형 OD(페이스밀·폼툴), 비회전 촬영은 축·스케일 방식을 손봐야 함.

## 8. 머신러닝의 위치 (배제 아님)

- **피한 것:** 일반화 안 되는 "마모 인식 CNN"(형상·재질·조명마다 라벨링+재학습). v3의 병목. 이걸 안 쓰게 된 게 승리.
- **지금:** 고전 CV만으로 충분(라벨 0 = 최대 범용). ML은 벤치에.
- **다시 넣을 자리 딱 하나:** 조명을 못 고쳐 이미지가 지저분할 때 → **강인한 절삭에지/실루엣 추출용 작은 이진 세그멘터**(정반사·연삭줄무늬에 강인, 이진이라 라벨 싸고 형상 일반화 잘 됨).
- **비지도/자기지도 옵션 (라벨 불필요 — 회전 촬영이 공짜 라벨 제공: 프레임 i,j 정답회전=(j−i)·Δθ):**
  - **A. 자기지도 회전 회귀기** — Siamese, `(cosNθ, sinNθ)`. 정반사 무시하고 회전만 보는 특징 학습 → ZNCC 대체·강인화.
  - **B. 재구성 기반 마모 검출** — 새 공구만으로 오토인코더 학습 → 마모 = 재구성 오차(정렬과 결합 필요).
  - **C. 대조학습** — 조명 불변 특징공간에서 정렬·차이 → 측정 바닥(~6µm) 돌파 여지.
  - 투입 시점: 정반사 심하거나, 측정 바닥 이하 마모, 형상이 크게 다를 때. 데이터 충분(공구당 420프레임 × 여러 공구).

## 9. 남은 과제 / 다음 단계

1. **더 많이 닳은 공구로 검증** — 마모가 ~6µm 바닥을 넘으면 지금 이미지로도 가로 픽셀이 뚜렷이 세지고 µm가 나옴. (파이프라인 민감도 확인)
2. **정밀 µm** 필요 시 **스케일바 교정**.
3. **촬영 개선(권장)** — 확산광/백라이트로 정반사 제거 + 날 끝 실루엣 선명 + (가능하면) 텔레센트릭으로 원근·스케일 차 제거 → 현재 파이프라인이 서브픽셀 정확.
4. **날 끝 N개 자동 검출** 구현 → 다른 날 개수 공구 일반화.
5. **옆면(`옆`) 처리** — 별도 진행 예정(측면 여유면 마모폭 VB, flank land width). 밑면=회전/후퇴, 옆면=마모폭 분업 가능.
